## Migration

No action is required for existing users. Simply download the latest version from the [new repository](https://github.com/OutrageLabs/Subterm/releases/latest).

**Arch Linux users:** Switch from `terx-bin` to `subterm-bin`:
```bash
yay -S subterm-bin
```
